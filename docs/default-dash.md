# The default dash (based on the Lovely Dashboard)

The project's default dash is `dashes/default/gt-default.json` ("GT default"), generated by `scripts/make_gt_default.py`. It was called `lovely-default` until 2026-10-24: a copy installed under that id keeps working.

- **Not a conversion.** The original Lovely Dashboard (Lovely Sim Racing, installed in SimHub as "Lovely Dashboard")
  runs on its own scripts and the Lovely plugin. Ours is drawn from scratch with shapes and text only, and only follows the
  layout of its main screen: tyres on the left, delta, gear and speed in the middle, times and fuel on the right, settings
  at the bottom. No asset of the original is used.
- **Data**: only FX Unleashed keys and generic SimHub properties, so it works in any game.
- **Setting changes**: changing TC, TC2, ABS, brake bias or map shows the new value large over the gear for 2 s. TC2 only
  works in iRacing (SimHub has no common property for it).
- **No start-up sequence**: some games don't report the ignition, and the dash would stay covered.
- **Left out** compared with the Lovely Dashboard: light and wiper icons, tyre wear and compound, weather, the clock and
  the other pages.

The original Lovely Dashboard's shift lights and redline warning come from Lovely Car Data, which its plugin fetches from
its own server: see `docs/rev-lights-plan.md`.
