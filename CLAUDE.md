# fx-unleashed-dashes: project rules

JSON dashes for the Simagic FX Pro screen, for FX Unleashed / FX Unleashed Enhanced (SimHub plugin). Dash format and tools:
`docs/reference/` (start with `create-dash-SKILL.md`).

**Read `docs/CONTEXT.md` first** (what the project is, how it works, its state). Then, depending on the work:
- `docs/rev-lights-plan.md`: the iRacing GT3s' shift lights, audit and measurements;
- `docs/PLUGIN-FORK.md`: what was asked of the plugin itself (now in FX Unleashed Enhanced) and the GT Pro Hub study.

## Goal
Recreate the real dashes of iRacing's GT3 cars, and a default dash in the spirit of the Lovely Dashboard.

## Rules
- Every dash passes the four gates before it is called done: `check`, `fit-bands`, `verify`, `render`
  (`python scripts/fx.py gates <dash>`, or `python scripts/gates_api.py <dash>` with SimHub open). Default pad 10,20
  (usable area 790x460).
- Ids in lower case with hyphens; the file is `<id>.json`; the JSON's `Id` matches the name.
- Check field and bind names with `fxdash schema` and `fxdash bindings` (or the plugin's API) instead of assuming them.
- Never invent iRacing car ids: take them from the plugin's log (`fx.py carids`), format `IRacing | <CarId>`.
- Never send anything to the wheel or install into SimHub unless the user asks (`install` with `--dry-run` first).
- Third-party material (the Lovely Dashboard, manuals, brand logos, other people's dashes) stays in `reference/`, outside
  git. No third-party assets or pictures in `dashes/` without permission.
- Dashes converted from other people's work (Redadeg's LMU dashes) and versions with brand logos live only in `out/`
  (outside git) and in the local SimHub. `dashes/` holds only our own work; the from-scratch dashes are generated by
  `scripts/make_*.py` and never edited by hand.
- Nothing is shared with the community (the FX Unleashed library, Lovely Car Data) without the owner deciding case by case.
- Fonts chosen on the wheel for the from-scratch dashes: 94 for labels, 110 for numbers (`scripts/dashkit.py`).
- No Simagic binaries or firmware in the repository.
- Talk to the user in Portuguese (Portugal); the repository itself is in English.

## Budgets
- Screen link ~25 KB/s: avoid many large dynamic elements changing at the same time.
- Picture memory (the screen's RAM drive): 336 KB usable, 512 B overhead per file.
